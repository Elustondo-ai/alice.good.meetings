# SPRINT-006 draft: touch buttons

The iPad has no keyboard in a meeting, so every key function needs a button there. Pablo asked for buttons "because now I can click". Cue buttons are not among them: on 22 November 2026 he removed the manual cue (SC-2), so the cue is the timer's alone. The strip appears only on touch screens, so the laptop screen is unchanged. It is part of the [specification](03.9-sprint-006-screen-specification.md).

## Rules

| ID | Rule | Ties to |
| --- | --- | --- |
| TB-1 | **Changed (SC-9; Q4).** Area E, the touch strip, is shown when the page has a coarse pointer (`any-pointer: coarse`) or `#touch` is in the address, and is hidden otherwise, so the laptop screen is as before. SC-9's "no control beyond SC-7" yields to this rule for touch screens only. | SC-9 |
| TB-2 | **Changed (22 Nov 2026, Pablo's decision, manual cue removed).** The strip holds three buttons in this order: Confirm, Clear, Avatar. There are no GOOD, LAND IT or STOP buttons. | Pablo 22 Nov (2) |
| TB-3 | **Changed (22 Nov).** Each does exactly what its key does: Confirm and Clear as SC-4 and SC-5 with `via` `button`; Avatar as the key A. | SC-4, SC-5, AV |
| TB-4 | **Touch target.** Every button on the page that is used by touch, area E, F and G buttons and the existing Start, Stop, Upload, Download and Remove, is at least 56 × 56 px (about 10 mm on his iPad), wider for words (at least 120 px for Confirm and Clear), with gaps of at least 12 px. | WCAG 2.2 target size; HIG 44 pt |
| TB-5 | **Changed (22 Nov).** Removed with the cue buttons. The Avatar button shows its state in words ("Avatar on" or "Avatar off"), never colour alone. | SA-3; Purpose |
| TB-6 | Enabled and disabled states follow SC-1: Confirm and Clear only while a candidate is present; a disabled button keeps its place and its cause appears as text. The Avatar button works in every state. | SC-1, SC-10 |
| TB-7 | A button acts on tap (a `click`, which Pencil and finger both give). No hover, long press, drag or double tap is needed; the buttons set `touch-action: manipulation` so a quick second tap does not zoom, and text on them cannot be selected. | iPad use |
| TB-8 | Feedback is the change of the screen itself within one frame: no sound, vibration or animation. | SA-16 |
| TB-9 | **Changed (SC-7, SC-9).** The input inventory is SC-7 plus the strip buttons, Send, the field, the ten presets and the keys 1 to 9 and 0. Every earlier input remains except the keys G, L and S, which Pablo removed on 22 Nov 2026 (SC-2). | SC-7; multimodal rule |
| TB-10 | Tab order follows the screen: Start, Stop, Upload, Download, Avatar toggle, then E, F, G, so a keyboard or switch user reaches every new control. | SC-8 |
| TB-11 | The strip's keys remain as before: A, Esc and Space; a button and its key give the same result and the same log line. | SC-10 |
