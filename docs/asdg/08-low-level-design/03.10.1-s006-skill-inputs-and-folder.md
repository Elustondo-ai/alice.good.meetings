# Preparation skill: inputs, folder and page templates

It is part of the [specification](03.10-sprint-006-preparation-skill-specification.md). The base has two levels so that it grows across jobs: `me/` holds what Pablo has done, by topic, and each job has its own folder that points to those topics.

```text
poc/context/knowledge/
  index.md              items, status, hashes, coverage, input hashes
  gaps.md               questions only Pablo can answer
  answers-from-pablo.md his written answers (he writes, skill reads)
  me/<topic>.md         what he did, depth to recall, gaps
  jobs/<company-role>/
    index.md  company.md  digest.md  presets.proposed.json
    topics/<topic>.md   this job's questions, answers, bullets, sources
    questions/typical.md  technical.md  behavioural.md
  runs/<date>.md        one report per run
```

## Rules

| ID | Rule | Ties to |
| --- | --- | --- |
| KI-1 | The input is the package Pablo uploads or places in `poc/context/interview/`: job description, résumé and ChatGPT's analysis as `.txt` or `.md`. The skill reads it and never edits, moves or deletes it. | Pablo 22 Nov; PK-2 |
| KI-2 | The skill does not change how ChatGPT makes the first package. | Pablo 22 Nov |
| KI-3 | It tells the three documents apart by content, not by file name, and asks when unsure. With the job description or résumé missing it stops, says which, and writes nothing. | |
| KI-4 | Optional inputs: `answers-from-pablo.md`, his own blocks in any page, a company name or address he gives, and the meeting date. | Pablo 22 Nov |
| KF-1 | The base lives in `poc/context/knowledge/`, which the existing `poc/context/.gitignore` already ignores. Before writing, the skill runs `git check-ignore` on that folder and stops if it is not ignored. | AGENTS.md; KV-1 |
| KF-2 | Names are lowercase slugs of at most 40 characters; a topic keeps its slug in every run (kept in `index.md`). | KU-6 |
| KF-3 | A `me/` page has these headings: Status (with the date of the last change, `new` until the next run), Evidence, Technical depth to recall, Gaps, Pablo's notes. | |
| KF-4 | A job topic page has: Where it comes from (requirement number and a quote of at most 25 words), Likely questions (kind, question, prepared answer, three bullets), Sources, Pablo's notes. It links to its `me/` page. | |
| KF-5 | Each page has an Alice block between `<!-- alice:begin -->` and `<!-- alice:end -->` and a Pablo block, which the skill never edits. | KU-2 |
| KF-6 | `index.md` records for each topic: id, slug, origins (J-n, R-n, C-n), status, the SHA-256 of its Alice block, the last run, and the SHA-256 of each input file. | KU-1 |
| KF-7 | A page is at most 600 words, so the digest stays small. All files are plain UTF-8 Markdown. | KO-4 |
