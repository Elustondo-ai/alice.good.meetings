# Preparation skill: re-runs and what feeds Alice

The base must grow without losing anything Pablo wrote, and the ten presets and the live answers must come from it. It is part of the [specification](03.10-sprint-006-preparation-skill-specification.md).

| ID | Rule | Ties to |
| --- | --- | --- |
| KU-1 | Run modes, chosen by comparing hashes: `first` (no `index.md`), `refresh` (the package changed: only affected topics), `answers` (new text in `answers-from-pablo.md`: only affected topics) and `research` (sources older than 30 days). It says which mode it chose. | Pablo 22 Nov |
| KU-2 | The skill rewrites only Alice blocks. Before rewriting one, it compares the block's hash with `index.md`; if Pablo edited inside it, his text is kept and the new text goes to `<slug>.proposed.md`, listed in the run report. | KF-5 |
| KU-3 | The skill only reads Pablo's blocks and `answers-from-pablo.md`, and never writes them. | |
| KU-4 | A topic no longer in the inputs becomes `retired` in `index.md`; its page stays and nothing is deleted. | |
| KU-5 | A new answer turns its topic from UNVERIFIED to confirmed, regenerates that Alice block and the affected proposals, and touches nothing else. | KT-2 |
| KU-6 | Ids and slugs never change. A run with unchanged inputs and no new answers changes only `runs/`. | |
| KU-7 | A topic Pablo marks `rejected` in his block (his "removes it") is not used in answers, bullets, digest or presets and is not regenerated; it stays in `index.md`. Topics and answers added in the last run carry `new` until the next run. | UC-10 |
| KO-1 | **Presets proposal.** `presets.proposed.json` holds at most 10 entries `{label, question, bullets}`: first "About me" for "Tell me about yourself", then topics ranked by `must` weight and likelihood. Pablo chooses the final ten. | 03.9.4 TP-9, Q9 |
| KO-2 | Before writing it the skill checks each entry: label one or two words, at most 16 characters, each word at most 11; at most three bullets of at most 120 characters; plain text; evidence only from confirmed or résumé-backed topics (KT-2). | TP-4, TP-13, TP-14 |
| KO-3 | The bullets of a preset are those of its topic page, so what he rehearsed is what the button shows. | |
| KO-4 | **Digest for live answers.** `digest.md` holds per topic the title, the bullets and a short answer, within a budget of 20,000 minus the characters of the package files (the S003 limit, PK-5). The run reports the budget and the size; over budget, the lowest-weight topics are dropped. | PK-5; C1 |
| KO-5 | The skill never writes into `poc/context/interview/`: Pablo copies the presets file and the digest there himself (Q5). | Q5 |
| KO-6 | Later, the service may pick the topic pages that match each question, so the limit applies per request and not to the folder (05 decides, C1). | C1 |
