## How a story file is kept

- File name: `NNN-short-name.md`, numbered in the order Pablo gives them, starting at `001`.
- Status is one of: Noted, In progress, Done, Dropped.
- The request is recorded in Pablo's own words, with the date.
- Each file stays at 50 nonblank lines or fewer; a long story links to its change record in `docs/asdg/07-planning/`.

## What each story file holds

1. **Request**: what Pablo asked for, quoted, and the date.
2. **What it means**: the story restated in one or two sentences, and what is out of scope.
3. **Done when**: the conditions that show it works.
4. **Files**: the ASDG files it changes or adds.
5. **Progress**: dated notes on what was done and checked, and what is still open.
6. **Decisions for Pablo**: anything waiting on his answer.

## Limits

A story file is a note, not an approval.
Commits, pushes, sprint changes and upstream proposals still need Pablo's own instruction each time.
